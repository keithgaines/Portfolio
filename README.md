# Keith Gaines — Portfolio

Personal portfolio website built to showcase software projects, case studies, and technical experience.

**Live Site:** https://keithresume.vercel.app

---

## Overview

This repository contains the source code for my portfolio website.

The site serves as a central location for presenting projects, technical experience, and case studies. It was designed to provide a simple and responsive experience while highlighting applications focused on business workflows, operational tooling, and modern web development.

---

## Features

* Responsive design for desktop and mobile devices
* Project showcase and case study sections
* External links to GitHub repositories and live applications
* Contact and professional profile links
* Simple and maintainable component structure

---

## Architecture

